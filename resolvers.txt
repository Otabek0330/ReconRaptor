# These are well-known, large, generally reliable public resolver
# services — NOT a raw scrape. Quality over quantity matters here:
# massdns/puredns spend time retrying every resolver that doesn't
# respond, so a big list full of dead/rate-limited entries can be
# SLOWER than a small list of resolvers that are all actually alive.
#
# If you need more throughput than this list provides for very large
# wordlists, the right move is NOT to just grab a raw 60k-entry list —
# validate it first with dnsvalidator so you're only using resolvers
# that actually respond:
#   https://github.com/vortexau/dnsvalidator
#   pip install dnsvalidator
#   dnsvalidator -tL https://raw.githubusercontent.com/trickest/resolvers/main/resolvers.txt -threads 100 -o resolvers_validated.txt
